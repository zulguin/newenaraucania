# Newen Araucanía

RPG de aventura inspirado en la mitología ancestral de Sudamérica. Beta pública en preparación para Windows y Android, con modo individual y guardado local.

Consulta [Versiones y descargas](https://github.com/zulguin/newenaraucania/releases). Los instaladores aparecerán allí cuando termine la primera compilación. No hay todavía una beta instalable publicada.
